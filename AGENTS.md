# Repository policy

Follow https://github.com/ORESoftware/my-ai/blob/main/AGENTS.md and original-agents.md.

TypeSpec and human-authored JSON Schema are independent peer authorities.
Duplicate shared interfaces; do not delete, move, or silently rewrite upstreams.
Preserve provenance and stop on disagreements. Generated witnesses are not authority.
Runtime implementation belongs in lib-core, not this interface package.
Never fabricate a Zed lock, a passing receipt, or runtime-conformance evidence.
