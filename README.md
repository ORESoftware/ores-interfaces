# ores-interfaces

Shared interface entry point for ORESoftware repositories.

This README-only initial commit establishes a pull-request base for the previously
empty repository. Contract definitions, TJSV validation, pinned legacy imports,
and tests will be introduced through a reviewed feature pull request.

Existing shared auth/platform consumers remain on `ores-otel/ores-interfaces`;
this initialization does not transfer that repository or change its contracts.

Parent engineering policy: https://github.com/ORESoftware/my-ai/blob/main/AGENTS.md
